v1.1.0 MAJOR May 2025
Global Launch -- AI Assistant, Security Badges and Continuous Monitoring
The biggest release since launch. PenChecker goes worldwide across 190+ countries with live AI-powered security assistance powered by Anthropic Claude, embeddable security badges, and automatic 24-hour monitoring for all verified domains.
NEWAI Security Assistant -- Powered by Anthropic Claude. Ask any question about your findings, get plain-English explanations and fix code in your exact tech stack. Full session history saved to database.
NEWSecurity Badges -- Embeddable SVG badges showing your live security score. 4 styles: dark, light, compact, detailed. Auto-updates after every scan. Reads from security_badges table.
NEWContinuous Monitoring -- Verified domains automatically re-scanned every 24 hours. Instant alerts for critical and high-severity findings.
NEWMulti-currency pricing -- Live detection via ipapi.co. Prices shown in your local currency. 20+ currencies supported worldwide.
NEWIndustry scan profiles -- 6 scan configurations: SaaS, Fintech, Healthcare, E-commerce, Government, General. Each adapts tests to your platform risk model.
IMPROVEDNotification panel now reads from database -- real notifications per scan event, finding severity, billing, and monitoring alerts. Mark read writes back to DB.
IMPROVEDDashboard rebuilt -- animated score ring SVG, time-based greeting, severity breakdown, findings table scoped per authenticated user session.
FIXEDScan INSERT failing silently -- target_domain (NOT NULL field) now correctly included in every scan payload alongside consent log record.
FIXEDScore field mismatch -- score renamed to security_score across all scan PATCH operations to match the database schema.
v1.0.4 SECURITY April 2025
Two-Factor Authentication and Session Hardening
Critical security upgrade for all accounts. TOTP two-factor authentication now available on all plans. Session tokens are validated and expire reliably on every dashboard page load.
NEWTOTP two-factor authentication -- Works with Google Authenticator, Authy, 1Password, and Bitwarden. 4-step setup wizard with QR code and download recovery codes.
NEWRecovery codes -- 8 single-use backup codes generated at 2FA setup. Downloadable as a plain text file.
SECURITYPassword reset tokens now expire after 1 hour (previously 24 hours).
SECURITYSession expires_at checked on every dashboard page load -- expired sessions redirect immediately to login.
SECURITYRate limiting on all auth endpoints -- maximum 5 failed attempts per 15 minutes per IP address.
IMPROVEDSign out all devices option added to Settings Security tab.
v1.0.3 MINOR March 2025
Domain Verification, Monitoring Toggles and Scan History
Full domain management with three verification methods, per-domain monitoring toggles, paginated scan history with search and filter, and the report viewer with severity tabs.
NEW3 domain verification methods -- DNS TXT record, file upload at /.well-known/penchecker-verify.txt, or HTML meta tag.
NEWPer-domain monitoring toggles -- Enable or disable continuous monitoring directly from domain cards. PATCHes domains.is_monitoring in real time.
NEWScan history page -- Paginated list (15 per page) with live search, 4 status filters, sort by score or date, and delete with confirmation dialog.
NEWReport viewer -- Load any past scan by ?id= URL param. Filter findings by severity. Expandable cards with server evidence and step-by-step fix instructions.
IMPROVEDScan page now pre-fills domain from ?domain= URL param, localStorage, or first verified domain automatically.
FIXEDOAuth callback not restoring dark/light theme after redirect from Google or GitHub.

PenChecker Launch -- The World Most Accurate Web Scanner

NEWCore scanner -- Technology fingerprinting first, then OWASP Top 10 testing. Only tests that apply to your detected stack are run. Zero false positives by design.
NEW5-phase scan pipeline -- Discovery, Headers, Injection, Auth and Session, Score. Each phase verified independently before scoring.
NEWEvidence cards -- Every finding ships with the actual server response that proves the vulnerability. Not a guess. Real proof.

NEWGoogle and GitHub OAuth -- One-click sign-up. No password required for OAuth users.
NEW5-step onboarding -- Guided first run: account, domain, industry, notifications, dashboard.
NEW32-page platform -- Full marketing site, legal framework, security blog with 10 articles, and complete dashboard suite. Dark and light mode on every page.
NEWLegal compliance -- Terms, Privacy Policy, Acceptable Use, DMCA. Consent logged immutably on every scan for legal audit trail.
