PenChecker AI
● Online
Scan: yoursite.com loaded
I've reviewed your scan for yoursite.com. You have 1 Critical, 2 High, and 3 Medium findings. Where would you like to start?
Fix the TLS 1.0 issue for me in Nginx
Here's the exact Nginx config fix. Add this to your nginx.conf server block: 
ssl_protocols TLSv1.2 TLSv1.3;
ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:
  ECDHE-RSA-AES128-GCM-SHA256;
ssl_prefer_server_ciphers off;
Then run nginx -t && nginx -s reload to apply. This disables TLS 1.0/1.1 and resolves CVE-2011-3389.

Vulnerability Explanation

Missing Content-Security-Policy Header

The server response does not include a Content-Security-Policy HTTP header. This allows execution of inline scripts and loading of resources from arbitrary origins, exposing the application to XSS and data injection attacks. CVSS Score: 7.5 (HIGH). CWE-693.

Your website can be hijacked by malicious scripts

Imagine someone slipping a fake sign into your shop that tricks customers into giving away their wallet. Without this security setting, attackers can inject their own code into your pages and steal your users' data or passwords. It takes 5 minutes to fix.
