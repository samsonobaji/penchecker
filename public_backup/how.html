Under the hood

How PenChecker works

From clicking "Start Scan" to a full security report in minutes — here's exactly what happens and why it matters.

The scan pipeline
5-phase security analysis
Every scan runs through five sequential phases. Each phase builds on the last, giving us a complete picture of your site's security posture.
Phase 1
Discovery & Fingerprinting
We probe your domain to identify what's running. Technology stack, server software, CMS, frameworks, JavaScript libraries, CDN presence, and IP geolocation. This lets us tailor all subsequent tests to your exact environment — no generic tests.
DNS resolutionTech detectionPort scanningWappalyzer rules
Phase 2
Headers & Transport Security
We analyse every HTTP response header and your TLS configuration. Missing security headers like CSP, HSTS, X-Frame-Options, and X-Content-Type-Options are flagged with specific fix instructions. TLS version, cipher suites, certificate validity, and HSTS preloading are all checked.
7 security headersTLS 1.0/1.1 detectionCert expiryHSTS preload
Phase 3
Injection & Input Testing
For active and deep scans, we send carefully crafted test payloads to discovered input points. SQL injection patterns, XSS vectors, path traversal attempts, and command injection markers are tested using a safe, non-destructive methodology. Every payload is designed to detect vulnerability without causing harm.
SQL injectionXSS (Stored/Reflected/DOM)Path traversalSSRF detection
Phase 4
Authentication & Session Security
We check how your site handles authentication. Cookie security flags (HttpOnly, Secure, SameSite), session fixation, open redirects, CSRF exposure, and default credential checks on discovered admin panels. We also look for exposed sensitive files like .env, .git, and backup archives.
Cookie flagsCSRF detectionOpen redirectsExposed files
Phase 5
Score Calculation & Report Generation
All findings are weighted by severity (Critical, High, Medium, Low) and aggregated into a score from 0–10 using our proprietary formula. The score penalises critical findings heavily while rewarding a clean security posture. The full report is generated with evidence, fix instructions, and CVSS scores for every finding.
CVSS v3.1 scoringFix code generationReport PDF/JSONAI analysis
Security score
What your score means
PenChecker scores range from 0 to 10. Here's how to read yours.
9.0 – 10.0
Excellent
No critical or high findings. Only minor informational issues if any. Your site follows security best practices across the board.
7.5 – 8.9
Good
No critical findings, possibly 1–2 high findings. A few medium issues to address. Better than 90% of sites on the internet.
5.0 – 7.4
Fair
Multiple medium findings and possibly 1+ high findings. Security needs attention. Prioritise the high findings immediately.
0 – 4.9
Needs Work
Critical or multiple high findings present. Your site is at significant risk. Use the AI assistant to prioritise and fix issues urgently.

The technology behind PenChecker
Built with the same tools used by professional penetration testers, packaged for everyday developers.
Claude AI
Anthropic's Claude analyses your findings and generates human-readable explanations and fix code tailored to your stack.
OWASP Rules
Our test suite is built on OWASP Top 10 and OWASP WSTG — the gold standard in web security testing methodology.
Distributed Scanning
Scans run in parallel across distributed workers, completing in minutes instead of hours. Deep scans finish in under 20 minutes.
Safe Testing
All payloads are non-destructive. We never modify data, delete files, or cause downtime. Stealth mode rate-limits requests to avoid WAF triggers.
Continuous Monitoring
Verified domains are automatically re-scanned every 24 hours. New vulnerabilities trigger instant alerts before attackers find them.
Data Privacy
Scan results are end-to-end encrypted. We never sell your data. Reports are private by default and only accessible by you.
