Quick wins

Security fixes you can
ship in 10 minutes

Small changes with a big impact on your security score.

Add HSTS Header
Forces HTTPS on all future visits. One of the highest-impact headers you can add in under 2 minutes.
Strict-Transport-Security:
max-age=31536000;
includeSubDomains
Easy — 2 minutes
Set X-Frame-Options
Prevents clickjacking attacks where your site is embedded in an invisible frame on an attacker's page.
X-Frame-Options: DENY
# or SAMEORIGIN if you
# need iframes
Easy — 1 minute
Secure Your Cookies
Three cookie flags that prevent session theft, CSRF, and interception over insecure connections.
Set-Cookie: session=abc;
HttpOnly; Secure;
SameSite=Strict
Easy — 5 minutes
Add Content-Security-Policy
Prevents inline XSS attacks by restricting which scripts, styles, and resources can be loaded on your pages.
Content-Security-Policy:
default-src 'self';
script-src 'self'
Moderate — 30 minutes

Security Glossary

B
Brute Force Attack
An attack that tries every possible combination of passwords or keys until the correct one is found. Mitigated by rate limiting, lockout policies, and multi-factor authentication.
AuthOWASP A07
Buffer Overflow
A vulnerability where a program writes more data to a buffer than it can hold, potentially overwriting adjacent memory and allowing arbitrary code execution.
Memory
C
CORS (Cross-Origin Resource Sharing)
A browser mechanism that controls how resources on one origin can be accessed by scripts from another origin. Misconfigured CORS allows unauthorized cross-origin access to sensitive data.
Headers
CSRF (Cross-Site Request Forgery)
An attack that tricks authenticated users into unknowingly submitting malicious requests. Fixed with CSRF tokens and SameSite cookie attributes.
OWASP
CVE (Common Vulnerabilities and Exposures)
A publicly disclosed cybersecurity vulnerability assigned a unique identifier (e.g., CVE-2021-44228). Each CVE has a CVSS score indicating severity.
Reference
CVSS (Common Vulnerability Scoring System)
A numerical score (0–10) that rates vulnerability severity. Critical = 9.0–10.0, High = 7.0–8.9, Medium = 4.0–6.9, Low = 0.1–3.9.
Scoring
H
HSTS (HTTP Strict Transport Security)
An HTTP header that tells browsers to always use HTTPS for a domain, preventing protocol downgrade attacks and cookie hijacking.
Headers Easy Fix
HTTP Header Injection
An attack where user-supplied input is included in HTTP response headers without proper sanitization, potentially enabling response splitting or cache poisoning.
Injection
I
IDOR (Insecure Direct Object Reference)
A vulnerability where user-supplied input is used to access objects (files, records) directly, without proper authorization checks. Changing /user/123 to /user/124 to access another user's data.
OWASP A01
Information Disclosure
When a system unintentionally reveals sensitive information to unauthorized users — stack traces, debug pages, server version headers, or internal paths.
Exposure
S
SQL Injection
An attack where malicious SQL code is inserted into an input field and executed by the database. Can read, modify, or delete database contents. Only possible on apps that use SQL databases — not Node.js ORM apps with no raw queries.
OWASP A03
SSRF (Server-Side Request Forgery)
An attack that tricks the server into making HTTP requests to internal resources or external systems, potentially exposing internal services or cloud metadata APIs.
OWASP A10
X
XSS (Cross-Site Scripting)
An attack that injects malicious scripts into web pages viewed by other users. Three types: Stored (persisted in DB), Reflected (in URL), DOM-based (client-side manipulation).
OWASP A03
XXE (XML External Entity)
An attack against XML parsers that allows attackers to read local files, make server-side requests, or cause denial of service through malformed XML with external entity declarations.
Injection
